HostelFix
A streamlined Android application for hostel maintenance and complaint management.

About
HostelFix bridges the communication gap between hostel residents and maintenance staff. Residents can report issues—such as plumbing, electrical, or network problems—and track their resolution in real time.

Features
Issue Reporting: Submit complaints with photos and descriptions.

Status Tracking: Monitor request progress from pending to resolved.

Role-Based Access: Distinct workflows for residents and administrators.

Tech Stack
Language: Kotlin

UI Framework: Jetpack Compose / Android Views

Architecture: MVVM

IDE: Android Studio
